### 🛠 What I do

I build and run production systems end to end — from API and database design to web clients, Flutter apps, and the servers they live on.

- **Backend & APIs** — Node.js / TypeScript (NestJS, Express), PHP (Laravel), REST, queues, background jobs
- **Web & mobile** — React / Next.js admin panels and client apps, cross-platform apps in Flutter
- **Integrations** — CRMs (Bitrix24, amoCRM), payments, WhatsApp &amp; Telegram bots, marketplace APIs
