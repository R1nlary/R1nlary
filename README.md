### Client projects (private code)

- Learning platforms: courses, tests, homework review, chats, mobile apps
- Courier delivery for Kaspi.kz orders: dispatch to store branches, shipping labels
- Tools for Kaspi.kz sellers: preorders, waybill printing, Kaspi Pay
- CRM automation in Bitrix24 and amoCRM: lead intake, freight pricing, WhatsApp requests to carriers
- Booking marketplace for beauty services in four countries, with local payment providers
- Maps, geocoding and routing on OpenStreetMap and PostGIS
